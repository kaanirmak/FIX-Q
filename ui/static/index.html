KRİPTOGRAFİK ALAN AÇIKLAMALARI VE PROTOKOL DETAYLARI

Standard TLS 1.3 Record Katmanları

  • Record Header (5B): Paket tipini (örn. 0x17 - Application Data) ve TLS sürümünü (Legacy 3.3) tanımlar.
  • Sequence XOR'd Nonce (12B): TLS 1.3'te bağlantı sırasına göre XOR'lanarak üretilen IV; ağ üzerinde ekstra yük oluşturmaz.
  • AES-GCM Ciphertext (Değişken): FIX verisinin ve 1 byte'lık orijinal paket tipi göstergesinin AES-GCM ile şifrelenmiş halidir. Confidentiality (gizlilik) sağlar.
  • Auth Tag (16B): Şifrelenmiş verinin bütünlüğünü (integrity) doğrulamak için üretilen MAC etiketidir.

Finora Hybrid PQC Shield Katmanları

  • X25519 Ephemeral Key (32B): Kuantum öncesi klasik güvenliği sağlamak için kullanılan ECDH geçici anahtarı.
  • ML-KEM-768 Ciphertext (1088B): FIPS 203 standardı Kyber tabanlı Kuantum Güvenli Anahtar Kapsülleme (KEM) verisidir.
  • AES Nonce (12B): Simetrik AES-256-GCM koruması için her paket başında üretilen rastgele başlangıç vektörüdür.
  • AES-256-GCM Payload (Değişken): FIX mesajının kuantum-güvenli ortak anahtarla şifrelenmiş gövdesidir.
  • ML-DSA-65 Signature (3309B): FIPS 204 standardı Dilithium tabanlı Dijital İmza. Kuantum-güvenli kimlik doğrulaması sağlar.
  • Length Prefix (4B): Tünel sınırlarını belirleyen büyük-endian formatında uzunluk verisi.
